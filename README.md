# Jeu des Livrets

Jeu pour s’entraîner aux tables de multiplication (livrets 1 à 12).

- Choix des livrets à travailler
- Deux modes : 4 choix ou je tape la réponse
- Chrono 30 s, 60 s ou sans chrono (20 questions)
- Séries bonus, meilleurs scores et liste des calculs à revoir

Ouvrir `index.html` dans un navigateur, ou publier le dépôt sur Netlify.
